# MCP 카메라 촬영 기준

2026-10-10 사용자 지정 배치와 두 번째 참고 사진을 기준으로 작성. 설치 계획이며 실제 장착·웹캠 입력 검증 완료를 의미하지 않는다.

현재 데모는 사용자 요청으로 실제 Cockpit 대신 태블릿 MCP를 촬영한다. 아래는 기존 실제 패널 촬영 참고 계획이며 태블릿 ROI는 별도로 설정한다. [태블릿 데모 안내](tablet-demo.md)를 따른다.

## 사용자 지정 배치

| 항목 | 기준 |
| --- | --- |
| 위치 | 두 조종석 사이 뒤쪽의 고정 지지대 |
| 방향 | 조종석 전방 MCP를 향해 약간 아래쪽 |
| 대상 | MCP IAS/MACH, HEADING, ALTITUDE 표시창 |
| 설치 원칙 | 조종사 시야·조종간·좌석 이동·비상 탈출 동선을 방해하지 않는 위치 |

선택 설정값의 숫자 창을 읽는다. 아래 비행 화면의 현재값이나 COURSE·VERT SPD 창을 선택 HDG·ALT와 혼동하지 않는다. 설치 원칙 충족 여부는 실제 배치에서 확인해야 한다.

## 참고 사진 전용 영역

두 번째 사진은 1672×941 픽셀이다. [설정](../configs/mcp-fixed-camera.json)은 이 이미지의 고정 영역을 정의하며 전체 패널 자동 탐지/영상 흔들림 보정은 없다.

| 대상 | ROI [left, top, right, bottom] | 단위 설정 | 사진 수동 판독 |
| --- | --- | --- | --- |
| IAS/MACH | [509, 282, 601, 313] | knots | 250 |
| HEADING | [692, 282, 786, 314] | degrees | 270 |
| ALTITUDE | [864, 282, 968, 314] | feet | 10000 |

단위는 설정 파일로 명시한다. 속도 숫자만 보고 IAS/MACH 모드를 자동 판별하지 않는다. 모드가 바뀌는 운용은 현재 PoC에서 미검증이다. Mach 입력은 unit=mach와 소수점 형식으로 별도 설정해야 하며, 카메라에서 모드를 식별하는 기능은 없다.

## 실제 촬영으로 전환할 때

1. 지정 위치에서 실제 프레임을 저장하고 해상도·구도를 기록한다.
2. 세 숫자 창의 실제 픽셀 영역을 다시 지정한다. 다른 해상도에 참고 사진 좌표를 그대로 적용하지 않는다.
3. 선택값 변경 전후·손 가림·흐림·반사 샘플과 수동 정답을 모은다.
4. 실제 프레임을 정지 이미지 CLI로 먼저 검증한다. 숫자 크기·초점·밝기에 따른 판독 실패를 기록한다.
5. 이후 카메라 연속 입력, 프레임 촬영 시각·끊김 감시, 안정화와 서버 연결을 구현한다.

렌즈·해상도·조명·카메라 거리·실제 ROI는 아직 미정이다. 참고 사진 1개 성공/실패로 실제 장비 인식 성능을 판단하지 않는다.

## 초기 사진 실행 결과

실제 macOS OCR 결과: 속도 250 knots, 고도 10000 feet. HEADING은 원문이 `OL2`로 나와 value=null, reason=invalid_format이다. 사람이 사진에서 읽은 270으로 출력값을 덮어쓰지 않았다. 여백을 바꾼 두 추가 crop에서도 같은 문자 오인식이 발생했다. 방위 숫자 인식 개선·촬영 조건 검증이 남아 있다.

결과/근거는 ignored `vision/output/mcp-fixed/`에 저장했다. 원본 참고 사진은 Git fixture로 추가하지 않았다. 이 실행은 정지 이미지이며 카메라 설치·연속 입력·Mach 실제 화면을 검증하지 않았다.

속도는 사용자 지정 촬영 대상에 따라 Vision 관측에만 추가했다. 기존 백엔드 ALT/HDG 비교·경고·Report와 속도 관제 검증은 확장하지 않았다. JSON 설명은 [결과 계약](../../contracts/vision-poc.md)을 참고한다.

## 방위 인식 개선 후 재검증

동일 사진의 방위 ROI를 그레이스케일로 변환하고 Lanczos로 4배 확대하여 OCR 입력으로 사용했다. 숫자 치환/정답 삽입 없이 OCR 원문 `270`을 얻었다. 이 전처리는 `heading.ocr_preprocessing`에만 설정한다. 전체 창에 동일 전처리를 적용하는 실험은 속도를 `052`로 오인식하여 채택하지 않았다. 고도/속도는 원본 ROI 입력을 유지한다.

현재 설정의 실제 실행 결과: ALT 10000 feet, HDG 270 degrees, speed 250 knots, 세 필드 reason=null. 원본 ROI는 `heading.png`, 실제 OCR 입력은 `heading-ocr.png`이며 결과 JSON에 두 경로·전처리 방법을 남긴다. 출력은 ignored `vision/output/mcp-heading-fixed/`에 보관했다.

자동 테스트 29개 통과, 기존 합성 고정 기대 사례 5개 회귀 통과. 이 사진은 설정 조정에 사용한 샘플이며 독립 평가 세트가 아니다. 여러 값/각도/촬영 조건에 대한 일반 성능과 실제 카메라 검증은 남아 있다.

## output 정리 이후 확인 위치

2026-10-10 문서 보관 요청으로 중복 실행 output을 삭제했다. 위의 output 경로는 당시 실행 기록이며 현재 보관 위치가 아니다. 최신 사진·최종 JSON·ROI와 전처리 근거는 [팀 공유 문서](../../docs/vision/README.md)에 보존했다. 첫 번째 참고 사진과 중간 실험 원본은 포함하지 않고 최종 MCP 사진 1개만 공유한다.
