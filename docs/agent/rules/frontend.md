# frontend 개발 규칙

React 화면은 서버 판정을 표시하고 독자적으로 오류를 재분류하지 않는다.
정상·불일치·판단 보류·장치 비가용을 색상과 문구로 구분한다. 보류 상태에서 이전 VERIFIED 배지를 유지하지 않는다.
근거 이미지·원본 음성·관측 시각·보류 사유를 확인할 수 있게 한다. 안내는 재확인 요청이며 자동 설정 변경 기능은 넣지 않는다.
실제로 없는 package.json·npm 명령을 실행 가능한 안내로 작성하지 않는다. frontend는 현재 골격이다. 계약이 준비되기 전 화면 개발은 fixture 사용임을 명시한다.
