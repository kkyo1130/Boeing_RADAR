# communication 개발 규칙

수신·복조·전처리·구간 분리·품질·채널 상태를 담당하고 최종 지시 판정은 backend에 맡긴다.
Audio Segment ID, 관측 시각, source/역할 추정 근거, 입력 경로, Quality Flag와 원본 참조를 전달한다. ATC/Pilot 역할을 순서만으로 확정하지 않는다.
실제 SDR과 녹음 파일 재생을 구분한다. SDR 장비·수신 방식은 미정이며 코드 없는 실행 명령이나 실제 수신 성공을 만들지 않는다.
원본 교신·경고 음성이 마이크로 재유입되는 상황과 입력 없음·중첩·지연을 고려한다. 허용된 실험 데이터만 사용한다.
