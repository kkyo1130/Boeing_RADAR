# vision 개발 규칙

기본 범위는 선택 고도 ALT와 선택 방위 HDG다. 2026-10-10 사용자 지정 MCP 촬영 대상에 따라 속도 표시창 관측도 선택적으로 지원한다. 속도 단위(knots/mach)는 설정에서 명시하고 모드를 추정하거나 기존 서버 비교 범위까지 자동 확장하지 않는다. 현재 고도·QNH/Baro는 범위 밖이다.
카메라 상태·프레임 시각·ROI·읽은 값·필드별 모델 점수·입력 품질·근거 이미지를 구분한다. 숫자를 추정해 채우거나 과거 값을 새 관측처럼 보내지 않는다.
FL은 feet로 변환한다. HDG 360 허용/0 변환은 계약에서 정하고 임의 허용하지 않는다. 실제 값 0을 결측값으로 취급하지 않는다.
장치 장애·가림·흐림·영상 지연·불안정한 연속 프레임은 상태와 사유로 전달한다. 품질 임계값과 안정화 프레임 수는 설정·평가 근거를 남긴다.
최종 NORMAL/MISMATCH/UNVERIFIED 판정은 backend 소유다. 카메라 입력과 영상 파일 검증을 구분한다. 테스트 정답은 평가에만 사용하고 인식 입력에 섞지 않는다.
