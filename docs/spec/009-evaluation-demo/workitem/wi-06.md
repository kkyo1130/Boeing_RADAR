# SPEC-009-WI-06: GLB 기반 모의 MCP

- 사용자 요청: 현재 조종석을 `.glb` 모델로 구현한다. 기존 사진 기반 MCP의 세 선택값과 수동 조작을 유지한다.
- 기준: dev `2e3dd77`; 브랜치 `codex/cockpit-glb`.
- 범위: 정밀 조종석 전체가 아닌 기존 MCP의 단순 입체 패널. 외부 모델 자산을 복제하지 않고 코드로 생성한다. 항공기 제어·서버 판정 변경은 제외한다.

## 구현

`frontend/scripts/build-cockpit.mjs`는 Three.js geometry를 GLTFExporter로 바이너리 GLB에 저장한다. 패널, 노브, 버튼, 나사, 표시창 노드를 분리하며 `public/models/cockpit.glb`는 약369KB다. `Cockpit3D.jsx`는 GLTFLoader로 실제 파일을 읽고 React 상태에 연결된 숫자/라벨 평면을 추가한다. OrbitControls 회전·확대와 정면 초기화, Raycaster 숫자 클릭 편집/노브 좌우 클릭 증감을 제공한다. 기존 입력창·키보드 버튼·범위 검사·가림·시나리오를 재사용한다. 숫자를 서버에 직접 전송하지 않는다. 촬영 모드에서는 정면 고정·회전 잠금, 로딩/WebGL 실패 메시지와 사진 전환을 지원한다. unmount 시 animation loop, controls, observer, geometry/material/texture/renderer를 해제한다. 뷰어는 lazy import하여 운영 화면에서 3D 모듈을 내려받지 않는다.

## 검증

- 모델 생성 `node frontend/scripts/build-cockpit.mjs`: 369208-byte GLB 생성.
- `node frontend/node_modules/vite/bin/vite.js build frontend`: 성공. 3D lazy chunk가 500KB를 넘어 번들 크기 안내가 남는다.
- frontend `node --test tests/*.test.js`: 기존 44개 통과.
- Playwright `frontend/e2e/cockpit.spec.js`: GLB HTTP200/바이너리 magic, 실제 3D 숫자 클릭→편집창→359 입력→증가0, 노브 클릭, 사진 전환/상태 유지, 촬영 모드 검증. 로컬 시연 5175에 연결한 별도 임시 config로 실행한다.
- Chromium 데스크톱 스크린샷으로 패널 표시와 전환을 확인했다. 실제 태블릿 GPU/터치, 카메라 재촬영·OCR 정확도, 전체 조종석 재현은 미검증이다.

## 자체 리뷰와 인수인계

공유 상태를 재사용하며 backend 판정/관측 계약은 수정하지 않았다. 모델에는 외부 텍스처/원본 사진이 포함되지 않는다. 실제 자산은 MCP에 한정되며 주변 PFD/ND·조종간은 제공하지 않는다. 사진/3D 전환과 시점 변경 시 Vision ROI를 다시 지정해야 한다. 외부 리뷰는 PR 제출 후 진행하며 자동 병합하지 않는다. 공개 사용법은 `frontend/README.md`에 기록했다. 로컬 5175 기본 페이지에서 확인 가능하다.
