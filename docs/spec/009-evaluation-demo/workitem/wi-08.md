## 범위·기준

2026-11-16 사용자 요청: 제공한 조종석 사진을 참고해 과도한 HDG·ALT 크기를 줄이되 Vision 인식 성능을 유지하고 변경 비율과 검증 결과를 보고한다. 기존 구현은 `codex/report-events-print-20261116`의 `65db0e0`이다. 변경은 `/cockpit`의 Vision용 3D 화면에 한정하며 기존 사용자 브랜치와 진행 중인 네 PR을 보존한다. 상태 원본은 TODO다.

## 구현

- `frontend/src/VisionCockpit3D.jsx`: GLB에 이미 적용된 MCP Y배율 1.5에 런타임 1.25가 곱해져 실제 1.875가 되던 중첩 확대를 제거하고 최종 Y배율을 0.8로 명시했다. 사진에 가까운 낮은 MCP 외형으로 약 57.3% 줄었다.
- HDG 창 너비 1.98→1.50(24.2% 축소), ALT 2.46→1.65(32.9% 축소). 검은 창의 높이와 베젤도 함께 맞췄다. IAS도 같은 계열 비율로 정리했다.
- 숫자 평면의 최종 세로 크기는 1.2×1.875=2.25→0.95×0.8=0.76(66.2% 축소). 가로는 3자리 1.05, 5자리 1.35로 별도 설정하여 숫자가 납작하거나 길쭉해지지 않게 보정했다. 이는 3D 좌표계의 비율이며 실제 제조사 치수 측정이 아니다.
- HDG·ALT 라벨의 크기·배경·위치를 축소된 창에 맞췄다. 숫자 문자열, 선행0, 수동 입력·노브·Raycaster 연결과 시점 전환은 유지한다.
- 고해상도 4배 텍스처, 기존 색상·대비·필터링, 실행 모델과 해시, 자동 ROI·OCR 보조 경로·범위 검사·불일치 보류·3회 안정화는 변경하지 않았다. GLB를 재생성하거나 모델을 재학습하지 않았다.
- `frontend/e2e/cockpit-proportions.spec.js`: 축소된 실제 3D HDG 창 클릭→0도 입력→시점 전환의 브라우저 회귀를 추가했다.
- `scripts/evaluation/compare-cockpit-proportions.mjs`: 두 프런트 서버의 실제 렌더 화면만 OCR 서버에 보내는 재현 도구다. 기대값은 표시 조작과 채점에만 사용하며 OCR 요청에는 이미지 이외의 정답·지시값을 전송하지 않는다.
- `docs/vision/cockpit-proportions-20261116.json`: 고정된 새 비교 세트의 조건·코드/모델 SHA256·항목별 실제 출력·보류 사유를 기록한다. 원본 이미지·모델·DB는 Git에 추가하지 않는다.

## 검증

### 표시 및 실제 실행 OCR

초기 조정용 4조합(270/3000, 0/12000, 90/3500, 359/9900)을 두 시점에서 확인했다. 이전 16개 판독 중 정답13/보류3/오답0, 최종 후보 정답15/보류1/오답0이었다. 이 조합은 비율 조정에 소비했으므로 최종 비교와 구분한다.
