- 완료 조건: 화면 버튼으로 입력을 실행할 수 있고 사전 등록 관제/실제 입력을 구분한다. 미인식·오래된/중복 프레임·채널 종료가 현재 정상으로 남지 않는다. 재현 가능한 실행 스크립트와 검증 기록을 제공한다.

## 구현

`backend/app/api/demo.py`는 opt-in 입력 API, `services/demo/adapters.py`는 PCM 검증·local Whisper·기존 구조 문법·v2 관측/근거 연결을 담당한다. `tracking.py`는 숫자를 마스킹한 주변 패널 이동을 찾는다. 실제 카메라 프레임→OCR→기존 Stabilizer3회→v2 intake→기존 validation·Incident·화면 순서다. 누락을 숫자로 보정하지 않는다. 카메라 조회 watchdog이 마지막 입력6초 경과 시 장애 이벤트를 기록한다.

`DemoPanel.jsx`는 장치 선택·미리보기·드래그 ROI·연속 프레임·관제 음성·복창 시작/종료를 제공한다. `demo-audio.js`는 선택한 MediaStream에서 받은 PCM을 WAV로 직렬화한다. 기존 audioFocus의 입력 우선권을 사용한다. 서버 역할을 프런트에서 재구현하지 않는다. 기존 structure_rules의 숫자 쉼표 정규화는 실제 ASR 표기를 지원하며 원문은 보존한다.

`scripts/setup-demo.sh`, `prepare-demo.py`, `run-demo.sh`로 설치·모델 다운로드·ATC 음성 생성·서버 실행을 재현한다. 공개 모델만 다운로드하고 원본 음성을 외부 API로 전송하지 않는다. 모델/녹음/DB는 Git에서 제외한다.

신규 테스트는 등록 관제와 미지원 복창, 숫자 원문 보존, 연속 안정화·0도·판독불가·중복/미래 프레임, 꺼진 어댑터, 숫자 변경과 패널 이동·추적 실패, 카메라 watchdog, PCM 부호/샘플레이트를 검증한다. 기존 backend475개, frontend39개를 보존한다.

## 자체 리뷰·제약

문법 검사는 같은 ASR 원문에 대한 검사로 독립된 인식 채널이 아니다. 등록 ATC에 모델 점수를 만들지 않는다. 카메라 타임스탬프·revision을 캡처 시점에서 고정하고 요청을 직렬화한다. 이전 결과가 늦게 도착하면 v2의 시각/채널/target 검사가 적용된다. 장치·서버 실패, 취소, 탭 숨김에서 입력을 중단한다. 파일 STT 시험을 실제 사용자 마이크 성공으로 보고하지 않는다.

패널 추적은 제한된 위치 이동만 지원하며 회전·줌/반복 영상·전체 실장비 오류율은 미검증이다. macOS OCR·로컬 Whisper 설치에 의존한다. 실제 사용자 복창과 카메라 설정 수정까지 이어지는 인수 시험은 남아 있다. 다른 WI는 일괄 완료하지 않는다. 외부 리뷰는 PR에서 대기한다.
