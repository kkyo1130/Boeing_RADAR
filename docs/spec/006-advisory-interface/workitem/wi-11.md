# SPEC-006-WI-11: B&G 상단 로고와 앱 아이콘

## 요청·구현

사용자가 제공한 로고를 앱 아이콘/로고로 적용하도록 요청하고 Downloads의 원본 PNG 경로를 지정했다. 기준 `ed524bd`.

- `public/branding/bg-logo.png`: 사용자 지정 PNG를 바이트 그대로 복사했다. 원본 SHA 비교 일치 확인. 재생성·배경 제거·원본 픽셀 변경은 하지 않았다.
- `public/branding/app-icon.svg`: 원본 PNG 데이터를 포함한 독립 정사각형512px SVG 래퍼다. 이미지 비율은 유지하고 남색 여백을 사용한다.
- `Operations.jsx`/`flight-theme.css`: 상단 기존 브랜드 옆에 로고를 표시한다. 라이트/다크 및 좁은 화면에서 비율을 유지한다.
- `index.html`: PNG fallback/SVG favicon, Apple touch PNG, manifest와 앱 제목을 연결한다. `public/manifest.webmanifest`는 앱 이름·시작 URL·독립 아이콘을 제공한다. 서비스워커나 오프라인 지원을 추가한 것은 아니다.
