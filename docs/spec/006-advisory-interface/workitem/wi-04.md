## 실행 계획 · SPEC v34

### 입력·출력과 범위

- 입력: 운영 화면·음성·실제 Vision/음성 서버 결과.

- 계약 원본: [상위 SPEC](../../006-advisory-interface.md#구현-계약과-처리-기준). 공통 필드·단위·ID는 SPEC-002를 따르며 사용자 결정과 기술안을 구분한다.
- 담당 완료 조건: AC-04. 이 WI의 결과만으로 다른 기능의 전체 완료를 선언하지 않는다.

### 선행 산출물과 착수 경계

- SPEC-006-WI-03: 단일 음성 큐·완료/중단/취소 기록.
- SPEC-003-WI-05: 값/health/지연 실촬영 결과.
- SPEC-004-WI-04: 음성 E2E 사례와 연결 증거.

위 산출물이 실제 연결되어야 통합 인수를 완료한다. 계약 초안·fixture로 수행할 설계와 단위 검증은 선행 WI 전체 완료를 기다릴 필요가 없으며, 그 경우 실제 연결 미검증을 명시한다. 이미 완료된 WI는 기존 수행 증거를 유지하고 아래 사례를 소급 실행했다고 기록하지 않는다.

### 처리 순서

오류 → 교신 중단 → 복구/대체 → 가림/끊김 → 재조회.

현재 저장소의 기존 모듈을 먼저 확장한다. 위 수정 영역 중 아직 없는 경로는 생성 후보이며 기존 구현이라고 표시하지 않는다. 입력·출력 경계에서 실패 사유와 ID를 보존하고 성공과 미실행을 구분한다.
