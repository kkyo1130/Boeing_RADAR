## 복명복창 불일치 상세 표시

상위 스펙 v3 D-006-01~02을 따른다. 서버가 판정한 불일치 항목별로 ATC값과 조종사값을 출처·단위와 함께 표시한다. 원본 근거 패널을 열거나 재발화하기 전에도 값을 볼 수 있어야 한다. 프런트엔드가 값만 비교해 서버 판정을 재분류하지 않는다.

| 사례 | 입력·전제 | 기대 결과 |
| --- | --- | --- |
| RB-01 | 서버 HDG 불일치, ATC 270°·Pilot 290° | HDG 불일치와 두 값·출처가 동시에 표시됨 |
| RB-02 | 서버 ALT·HDG 모두 불일치 | 각 불일치 항목에 대응하는 두 값과 단위를 표시하며 서로 바꾸거나 다른 지시 값을 섞지 않음 |
| RB-03 | Pilot 값 null·사유 있음, 서버 판단 보류 | 값을 0으로 채우거나 불일치로 표시하지 않고 보류와 사유를 표시 |
| RB-05 | 복명복창 불일치 결과 표시 후 PTT 누름 | 확인 버튼을 요구하지 않고 같은 지시에 대한 수정 발화를 시작. 서버 재검증 전에는 해결로 표시하지 않음 |
| RB-04 | 서버 HDG 불일치, ATC 0°·Pilot 10° | ATC 0°를 유효한 값으로 표시하고 누락·판독 불가로 바꾸지 않음 |

수정 안내는 [D-007-01](../../007-closed-loop.md)에 따라 해당 지시의 전체 항목을 다시 말하도록 요청한다. 예: ALT·HDG 지시에서 HDG 불일치 시 두 항목 모두 재발화하도록 안내한다.

위 사례는 완료 조건이며 검증은 미실행이다. 불일치 결과 이후에는 별도 확인 버튼 없이 PTT로 수정 발화를 시작할 수 있다. PTT를 눌렀다는 이유로 알림 확인이나 오류 해결 이벤트를 만들지 않는다. 수정 발화 제출 후에는 SPEC-004의 비교 대기 입력 차단 정책을 따른다.
