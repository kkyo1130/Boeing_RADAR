# SPEC-004-WI-05: 관제·복창 음성 파일 직접 STT

2026-11-12 사용자 요청: 마이크 없이 관제와 조종사 복명복창 음성 파일을 각각 넣고 STT 변환 결과로 판정하는 버튼과 사용 설명을 구현한다.

## 기준·범위

ZIP 기반 음성/운영 기능(origin/dev740df89)과 현재 로컬 통합 작업을 보존한다. 파일 업로드를 스피커 재생/마이크 수음과 구분한다. 기존 Whisper·BERT·서버 판정을 재사용하며 카메라 관측을 만들어내지 않는다. 기존 사용자 checkout과 report/Vision/DB 변경은 유지한다.

## 구현과 계약

- `frontend/src/file-speech.js`: 파일10MB/0.1–30초 검사, OfflineAudioContext 디코딩·채널 평균·16kHz PCM16 WAV 변환, ATC/PILOT 요청 분리. PILOT는 명시적 현재 atc_input_id 필요. 파일 재생/마이크 요청/원고 자동 대입은 없다.
- DemoPanel에 관제·복창 각각 파일 입력과 STT 버튼, 제한·호출부호·순서·카메라 경계 안내를 추가했다. 마이크 미연결이어도 파일 버튼을 사용할 수 있다. 관제 미채택·새 입력 처리중·연결 끊김·종료·중복 입력·현재 지시 변경 시 복창을 보호한다. 처리중에 입력/모드를 잠그고 종료/비행 변경 시 이전 작업의 UI 반영을 막는다.
- 파일은 현재 접수 구간 시각을 쓰며 녹음 원본 시각으로 가장하지 않는다. 변환한 실제 음성만 서버에 보내고 transcript/목표값은 요청에 넣지 않는다. 기존 음성 우선순위 예약과 근거 저장을 재사용한다.
- `/readback`에 optional input_mode=file_upload를 추가했다. 미지정 legacy 마이크 요청은 유지한다. ATC 기존 file_upload 경로를 재사용한다. v2 role_basis에 ATC_FILE_UPLOAD/PILOT_FILE_UPLOAD를 추가하고 JSON Schema/계약 문서/역할 검증을 같이 갱신했다. ATC/Pilot 역할을 바꿔 보내는 요청은 거부한다.

## 완료 조건과 검증

- frontend75개 테스트 및빌드 통과. stereo 평균, 실제 샘플 WAV 인코딩, file payload의 지시 연결/원고 미대입, 초과 크기/길이/디코딩 실패 거부 포함. 브라우저 Codec 디코딩은 단위 테스트에서 OfflineAudioContext 경계를 mock했고 실브라우저 파일 선택은 미실행이다.
- backend 전체684 passed/6 skipped, Starlette 경고1. 파일 ATC→파일 PILOT 일치·불일치, 역할 근거 구분, 기존 마이크 경로 및 계약 회귀 포함. 최초 추가 테스트2건은 동일한 과거 접수 구간을 재사용해 Pilot-before-ATC로 거부됐으며 테스트의 실제 순서 시각을 바로잡았다. 서버 순서 검사는 완화하지 않았다.
- 별도 임시DB에서 ZIP bundled synthetic baseline.wav를 실제 로컬 Whisper/BERT로 ATC/PILOT 각각 처리. 두 transcript 모두 `Radar 1-2-3 climb and maintain 3,000 feet, heading 2-7-0.`; readback NORMAL, setting UNVERIFIED. 마이크 사용 안 함. 테스트DB는 제거하고 실제 비행DB는 유지했다.
- 사용자 브라우저 제어 host가 unavailable이라 파일 선택 버튼을 실제 클릭하는 검증은 미실행이다. frontend build/코드 제공·서버 OpenAPI/실제 ASR/API 검증과 구분한다.

## 자체 리뷰·인수인계

원본 음성/역할/호출부호/지시 연결, 음성 일치와 Cockpit 설정 확인의 분리, 파일→현재 접수 시각, 모델 실패 보류, 마이크/시나리오 레거시 경로 보존을 검토했다. 서버 재시작은 기존 `.demo/zip-ai.db`로 수행한다. 사용법은 docs/demo/file-speech.md. 전용 브랜치/PR 결과는 후속 기록한다. 외부 리뷰·실마이크/실카메라 검증을 수행한 것으로 기록하지 않는다.
