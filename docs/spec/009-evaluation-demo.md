## 평가 지표 정의 초안

정답 정상/오류와 결과 NORMAL/MISMATCH/UNVERIFIED의 2×3 표를 사용한다. 실제 정상에서 정상 A·오탐 B·보류 C, 실제 오류에서 거짓 정상 D·정상 탐지 E·보류 F로 집계한다.

- 탐지율: E / (D+E+F)
- 거짓 정상률: D / (D+E+F)
- 오탐률: B / (A+B+C)
- 경보 정확도: E / (B+E)
- 전체 보류율: (C+F) / (A+B+C+D+E+F)
- 오류 사례 보류율: F / (D+E+F)
- 미탐률을 (D+F)/(D+E+F)로 보고하면 보류 포함 정의라고 명시하고 거짓 정상과 함께 제시한다.
- 분모가 0인 지표는 N/A다. 단순 숫자 인식 정확도, 판독 가능한 사례의 정확도, 전체 보류율을 분리한다.
- Vision 지연은 프레임 촬영→관측 제공, E2E 알림 지연은 정답 오류 발생→화면 표시로 측정한다. 시간 기준·동기화·평균/분위수·최대값을 기록한다.

목표 숫자와 합격 기준은 Q-05에서 확정한다. confidence 점수를 백분율 정확도로 바꾸지 않는다. 임계값 선택에 사용한 데이터와 최종 평가 데이터를 분리한다.
