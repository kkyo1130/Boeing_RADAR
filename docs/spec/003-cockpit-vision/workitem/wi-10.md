# SPEC-003-WI-10: YOLO MCP 검출과 CNN OCR 복구

## 요청·완료 조건

사용자가 기존 YOLO + CNN 경로로 복구하고 연결된 실제 웹캠으로 확인하도록 요청했다. 이전 비율/이동/리포트 변경은 보존한다. 기준은 로컬 SPEC-008-WI-07의 `849b6a9`이며 원격 기준과의 차이는 선행 작업이다.

- Operation 자동 영역 탐지와 매 프레임 재탐지, Vision LAB 전체 프레임 입력은 학습된 MCP YOLO → 패널 내부 숫자 창 분리 → CharacterCNN을 사용한다.
- 수동 영역 설정은 사용자가 지정한 창에 같은 CharacterCNN을 사용한다. Apple Vision 자동 대체나 숫자 목표값에 의한 위치/판독 보정은 사용하지 않는다.
- 낮은 YOLO 점수(.5 미만), 경쟁 패널, 프레임 가장자리 잘림, 불완전한 3/5개 숫자, 낮은 CNN 점수(.75 미만)는 null/보류다. 기존 backend 새 관측 3회 확인·stale·지시 변경 초기화·유실 후 재탐색을 유지한다.
- 실제 웹캠 새 프레임에서 사용자 정답과 대조하고, 고정 화면 성공과 이동·값 변경·가림 인수 결과를 구분한다. 학습/개발용 영상을 인수 결과나 일반 정확도로 재사용하지 않는다.

## 구현

- `vision/yolo_cnn_runtime.py`: 학습된 단일 MCP 클래스 확인, 모델 SHA 검증, 공통 YOLO/CNN 런타임. 960px와 640px 입력에서 기존 공간 검출 게이트를 적용하고 YOLO가 허용한 패널 내부에서만 숫자 창을 찾는다. 정답 문자열/지시/조종석 상태를 입력받지 않는다. 좌표를 원본 프레임으로 환산하며 양쪽 창이 없으면 OCR에 넘기지 않는다.
- 공간 게이트는 요청 단위 1프레임으로 적용한다. 서버의 세션별 숫자 3회 확인과 LAB의 새 프레임 3회 확인이 최종 관측 전 시간적 안정화를 담당한다. 이 변경은 기존 CLI의 패널3회+값3회와 동일한 정책이라고 표현하지 않는다.
- `backend/app/services/demo/{adapters,tracking}.py`: 자동 영역/연속 추적은 YOLO, 숫자는 공통 CNN. 수동 추적은 기존 패널 템플릿을 유지하며 숫자 엔진만 CNN으로 통일한다. 근거/관측 시각/DB/안정화/판정은 기존 흐름이다.
- `vision/ocr_web.py`: `/infer-frame`은 같은 전체 파이프라인, `/infer`는 지정 crop의 CNN이다. Apple Vision fallback을 제거하고 `/health`에 실제 모델 SHA와 비활성 여부를 노출한다.
- `frontend/src/WebcamOCR.jsx`: 실제 사용 엔진을 YOLO + CNN으로 표기한다.
- `scripts/run-yolo-cnn.sh`: API8019/Vision8766/frontend5179 실행. 모델은 로컬 경로/환경변수로 지정하고 이전 OS OCR 실행 파일 환경변수를 제거한다. 기존 DB와 호출부호 설정을 유지한다.

## 실장비 진단·모델 개발

사용자 정답 HDG270/ALT03000은 채점에만 사용했다. 첫 웹캠은 숫자 획이 붙어 창 분리 실패. 사용자가 준비됐다고 한 후 실제 카메라0/AVFoundation 1920×1080 새 프레임을 확보했다. 새 비율에서 기존 YOLO는 모델 점수 약 .24로 .5 기준에 미달해 보류했다. 수동으로 픽셀의 숫자 창만 좁혀 분리한 진단에서는 기존 CNN이 두 값을 읽었다. 넓은 crop은 가장자리 반사까지 포함해 ALT 숫자 분리에 실패했다. 이 수동 진단은 자동 인식 성공으로 계산하지 않는다.

기존 모델/CNN 원본은 보존한다. 새 YOLO 후보는 `.demo/yolo-cnn-webcam/adaptation/`에 별도 생성한다. 같은 세션 개발 프레임2장의 패널 외곽을 픽셀에서 표시하여 train에만 넣었고(각20회 가중 반복, 독립40장 아님), 기존 train120장/val30장을 분리했다. 학습 명령·설정·provenance·로그는 해당 로컬 폴더에 보관한다. 30장 val은 기존 학습 개발자료로, 과거 blind40장 테스트 또는 새 독립 평가가 아니다. 이번 후보에는 과거 88.86% 수치를 붙이지 않는다.
