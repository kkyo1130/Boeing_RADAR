# SPEC-008-WI-10: PDF 요약과 전체 지시 로그

## 요청·기준·완료 조건

2026-11-18 사용자가 검토한 PDF 형식(제품명 없는 머리글, 전문 보고서 서체·표, 전체 요약 1쪽 + 지시 로그)을 실제 앱의 PDF 다운로드에 반영한다. 기준 dev `7450568`, 전용 브랜치 `codex/report-summary-register`. PDF 출력만 변경하며 UI/JSON/저장 판정은 보존한다.

- 요약은 지시/항목/오류/미확인을 구분하고 주요 사건 최대3건을 보여준다. 나머지 사건은 로그에 모두 표시한다.
- 적용된 ATC의 고도·방위 항목을 순서대로 표시하고 원본 instruction ID로 최신 저장 판정·관측 시각·사건 이력을 연결한다.
- 부분 지시가 이전 지시의 다른 필드를 가져오지 않는다. 호출부호 보류, 최신 stale/미판독, 지시 대체, 재발, legacy 연결 누락을 정상/해결로 바꾸지 않는다.
- 경로·위치·비행 단계 미수집 시 추정하지 않는다. 샘플의 가상 노선/숫자를 제품에 넣지 않는다.
- 정상·미확인·오류·다수 사건·빈 비행·장문·페이지 경계·동결 불변을 검증하고 API 산출 PDF를 시각 확인한다.

## 구현

- `backend/app/services/reports/register.py`: 동결 `safety.timeline`의 applied ATC가 명시한 ALT/HDG만 항목으로 만든다. 원본 INPUT_RECEIVED의 targets에서 instruction ID를 연결하며, legacy는 같은 필드/expected에 유일한 체크 연결만 사용한다. 불명확하면 Unlinked로 남긴다. 최신 동일 검증 snapshot의 readback/setting/callsign을 함께 읽으며 관측 시각은 observation ID로 원본 payload에 연결한다. 서로 다른 시점의 정상 체크를 합성하지 않는다.
- `backend/app/services/reports/pdf.py`: 네이비·세리프 제목·줄 단위 표, 제품명/로고 없는 머리글, 요약 1쪽 + 자동 페이지 나눔 지시 로그를 구현했다. 요약의 지시 건수는 기존 정의, ALT/HDG 항목 수는 projection에서 산출한다. 주요 사건은 미해결 우선 최대3건이며 전체 사건은 해당 항목 아래 기록한다. CALLSIGN/legacy 미연결 사건도 별도 영역에 보존한다. 재발을 합치지 않고 SUPERSEDED/UNVERIFIED와 실제 경고 재생 완료를 구분한다.
- API 경로/소유권/종료 전409/파일명/메타데이터 제목/작성자 공백 유지. 신규 DB·스키마·UI 변경과 네트워크/AI 호출 없음. 기존 판정·원본 JSON은 수정하지 않는다.
- 노선·단계는 현재 미수집이므로 샘플의 ICN-SFO/비행 단계/40·48건을 하드코딩하지 않는다. 최신 판정과 과거 전체 일치 요약이 다를 수 있음을 본문에 표시한다. 시각은 날짜 포함 UTC, 소수 부분의 불필요한 뒤쪽0만 제거한다.
