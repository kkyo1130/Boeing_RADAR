### 선행 산출물과 착수 경계

- SPEC-001-WI-01: 내용 보존된 backend와 이동 검증 근거.

위 산출물이 실제 연결되어야 통합 인수를 완료한다. 계약 초안·fixture로 수행할 설계와 단위 검증은 선행 WI 전체 완료를 기다릴 필요가 없으며, 그 경우 실제 연결 미검증을 명시한다. 이미 완료된 WI는 기존 수행 증거를 유지하고 아래 사례를 소급 실행했다고 기록하지 않는다.

### 처리 순서

필드 의미 정의 → 현재/확장 차이 표 → endpoint/오류 확정 → 생산자·소비자 fixture 검증.

현재 저장소의 기존 모듈을 먼저 확장한다. 위 수정 영역 중 아직 없는 경로는 생성 후보이며 기존 구현이라고 표시하지 않는다. 입력·출력 경계에서 실패 사유와 ID를 보존하고 성공과 미실행을 구분한다.
