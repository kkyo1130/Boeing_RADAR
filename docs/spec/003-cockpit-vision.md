## 목적과 범위

선택 ALT·HDG를 영상에서 읽고 읽지 못한 경우와 근거를 전달한다. 사용자 지정 MCP 구도에 따라 속도 표시창은 Vision 관측만 선택적으로 추가한다. 서버의 속도 비교는 이번 범위가 아니다.

포함 범위는 아래 workitem의 산출물이다. 실제 항공기 제어·QNH/Baro와 다른 기능의 소유 계약은 제외한다. 2026-10-10 사용자 요청으로 실제 Cockpit 대신 태블릿의 모의 MCP를 촬영하는 데모 환경을 채택했다. 수동 MCP 화면은 frontend, 촬영·OCR·상태 감시는 vision 소유다. 실제 항공 계기의 성능 검증은 별도로 남긴다.

## 동작·계약·미정 사항

공통 단위·ID·시각·null·품질·근거는 [SPEC-002](002-observation-contracts.md), 판정은 [SPEC-005](005-safe-validation.md)를 따른다. 해당 계약 확장 전 현재 API가 지원한다고 가정하지 않는다.
미정 사항 Q-01~Q-05와 영향 범위는 [서비스 방향](../service/overview.md#결정이-필요한-항목)에 있다. workitem의 선행 결과와 필수 결정이 확보된 범위만 구현한다. fixture 성공과 실카메라·마이크·수신 성공을 구분한다.
