## 동작·계약·미정 사항

미정 사항 Q-01~Q-05와 영향 범위는 [서비스 방향](../service/overview.md#결정이-필요한-항목)에 있다. workitem의 선행 결과와 필수 결정이 확보된 범위만 구현한다. fixture 성공과 실카메라·마이크·수신 성공을 구분한다.

## 이미 구현된 기반

기본 SQLite SafetyEvent·관측 스냅샷·변경 전후 값·시간순 조회가 있다. 근거/health/보류/사용자 확인/억제 확장과 자동 집계/리포트는 없다. 상세 실행 근거는 [구현 현황](../IMPLEMENTATION_STATUS.md)을 참조한다. 아래 WI는 확장 요구까지 포함하므로 이 기반만으로 done 처리하지 않는다.
