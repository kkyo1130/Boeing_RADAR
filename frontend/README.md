# 태블릿 MCP 촬영 화면

React/Vite 기반 모의 MCP 화면이다. 사람이 선택 ALT·HDG·IAS를 바꾸며 Vision은 태블릿을 촬영한 카메라 영상만 읽는다. 서버 판정/비행 운영 UI는 아직 구현하지 않았다. 이 화면의 선택값을 Vision에 전달하는 API·메시지·자동 설정 기능은 없다.

기존 [Cockpit 참고 사진](../docs/vision/assets/mcp-reference.png)을 배경으로 사용하고 세 선택 숫자 창만 덮어 그린다. 주변 PFD·ND·COURSE·VERT SPD·스위치는 고정된 사진이며 실제 상태나 선택값과 동기화되지 않는다. MCP 확대(기본)와 전체 조종석 보기를 전환할 수 있다. 사진을 중복 저장하지 않고 Vite에서 공유 자산을 가져온다.

## 실행

Node.js 20.19+ 또는 22.12+에서 frontend 디렉터리 기준으로 실행한다.

```sh
npm ci
npm run dev
```

PC에서는 `http://localhost:5173/`, 같은 Wi-Fi의 태블릿에서는 Vite가 출력한 Network 주소를 연다. localhost는 각 기기 자신을 뜻하므로 태블릿에는 PC의 LAN 주소를 사용한다. 네트워크 격리/방화벽 환경이면 접속되지 않을 수 있다. 확인 명령은 `npm run build`다.

## 조작·촬영

- 기본값: ALT 03000 feet, HDG 270 degrees, IAS 250 knots.
- 숫자 창 터치로 정수 입력. HDG 0~359, ALT 0~99900, IAS 0~999. 범위는 모의 표시 형식이며 항공기 운용 범위가 아니다.
- +/− 버튼: ALT 100ft, HDG 1도, IAS 1knot씩 조절. 방위 다이얼은 359↔0으로 회전한다.
- 기준값/ALT 변경/HDG 변경/초기화는 수동 입력 예시다. 오류 여부를 판정하지 않는다.
- 숫자 창 가리기는 화면에서 해당 숫자만 숨긴다. 실제 손 가림·흐림·반사 실험은 별도로 한다.
- 촬영 모드는 안내·조작 패널을 숨기고 사진을 화면에 맞춘다. 값은 사진 위 숫자 창을 터치해 직접 입력한다. 설정 보기를 누르면 다이얼·가림·시나리오 버튼을 사용할 수 있다. 전체 화면은 설정 화면에서 지원 브라우저에 한해 동작한다.

가로 방향과 밝기·카메라·태블릿 위치·확대 여부를 고정한 다음 촬영 모드에서 ROI를 설정한다. 화면 회전, 모드 전환, 확대 전환, 주소창 크기 변화로 숫자 창 위치가 바뀌면 다시 설정한다. 새로고침 시 초기값으로 돌아간다. 값은 서버나 브라우저 저장소에 보관하지 않는다. IAS/Mach 자동 모드 전환은 지원하지 않는다.

카메라 캡처·ROI 설정·스트림 실행은 [태블릿 데모 안내](../vision/docs/tablet-demo.md)를 따른다.
